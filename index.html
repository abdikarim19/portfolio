Dutchie

Splitting a bill,
down to the cent.

In development · Not launched

Source not publicly available

Dinner is shared. What everyone owes isn’t always obvious.

I’m collaborating on a mobile app that reads a receipt, lets people claim their items, and calculates their share of tax, tips, and discounts. My work includes the TypeScript split engine: the part that makes sure the numbers agree.

Make the math explainable
Amounts stay in integer cents. Largest-remainder rounding assigns the leftover cents deterministically, and final shares must reconcile to the receipt total.
Keep receipt reading off the device
The camera sends a receipt to a Supabase Edge Function backed by Gemini. Extracted items are reviewed before they become part of a bill.

Where it stands: the native app, receipt reader, and split engine are implemented. Billing state is stored on-device; shared multi-user billing is still being built. Dutchie does not move money.

Built with TypeScript · React Native · Expo · Supabase Edge Functions · Gemini

HagSpot

A place to study.
Less time looking.

Modernization implemented · Not launched

View HagSpot repository

Finding a room and knowing how busy a space is are different problems.

I built HagSpot around campus study spaces, with room reservations and QR-based check-ins. The modernized web application replaces the legacy PHP interface with a typed Next.js application.

Separate reservations from presence
Bookable rooms and open study areas have separate data models. A reservation describes a time slot; a check-in describes someone’s recent presence.
Give presence an expiration
Check-ins expire after 20 minutes and can be refreshed or ended. Authentication gates booking and check-in actions; Drizzle maps the domain to PostgreSQL.

Where it stands: modernization code is complete, with service configuration required for bookings and presence. The browsing demo uses sample availability; it is not a live campus occupancy feed.

Built with Next.js · TypeScript · Supabase · PostgreSQL · Drizzle · Tailwind CSS
